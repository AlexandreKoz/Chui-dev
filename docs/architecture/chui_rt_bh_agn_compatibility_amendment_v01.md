# CHUÍ RT/BH/AGN — compatibility amendment v01 (pass 01)

Status: proposed engineering amendment recorded by the pass-01 implementation;
the five design specifications are NOT edited. Each item states the conflict,
the decision and its consequence. Audit 01/03 should confirm or revise.

| ID | Conflict / open choice | Decision | Consequence |
|---|---|---|---|
| A1 | Proposed key spellings (master §7) vs existing `physics.enable_black_hole_agn`/`bh_*` keys | New typed structs `physics.rt`, `physics.bh_engine`, `physics.agn` with `physics.rt_*`, `physics.bh_*`, `physics.agn_*` spellings (`core/config_rt_bh_agn.hpp`). `physics.bh_engine_model = legacy_host_cell` (default) runs the unchanged legacy callback. The reference engine reuses `bh_alpha_bondi`, `bh_epsilon_r`, `bh_use_eddington_cap` (must agree with `bh_eddington_cap`), `bh_enable_seeding` (must agree with `bh_seed_model`) and the `bh_*_si` constants; `bh_epsilon_f` and `bh_feedback_coupling_efficiency` are legacy-only and rejected when present with `reference_v1`. | Disabled runs: normalized text and config hash byte-identical (new blocks dumped only when enabled; non-default disabled values rejected as inert keys). |
| A2 | BH companion §2 asks for species SoA keyed by stable ID | Advanced BH truth is the particle-indexed module sidecar `chui_bh_engine_v1` (`BlackHoleEngineRecord`, schema 1), keyed by particle ID, `kSpeciesMask` (BH) requirement. Migration, reorder and native restart use the existing module-sidecar machinery (precedent `chui_stellar_population_v1`). Legacy `BlackHoleParticleSidecar` lanes keep their meaning; for the reference engine `subgrid_mass_code` mirrors the horizon mass, particle mass = `M_bh + M_disk + M_pending_wind`. | No restart schema bump for BH state; science-snapshot export of the new lanes is NOT implemented (gap). |
| A3 | RT §3 canonical moment state; restart numbering | Core-owned `RadiationMomentSoa` (`SimulationState::radiation`), patch-keyed leaf records, group-major lanes, comoving `a^4` convention at physical edges; empty when disabled. | A4 | BH01 halo provider | `physics.bh_seed_model = halo_fof_serial` uses `FofHaloFinder::buildCatalog` on the local state, admitted only for one rank.
